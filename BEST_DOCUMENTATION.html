Coverage gaps without the reference layers: feature proxies calibrated on public-leaderboard moments

Best Documentation entry · Zindi user skaiea13 · final selected submissions gki9K7jy (public RMSE 0.075383, 16 October 2026) and 6BNL8pZ3 (public RMSE 0.075416, 17 October 2026)

Data: the challenge package (Overture release 2026-08-19.0 extracts, ACS housing units, census tract boundaries, strata tables and the sample submission files) and tract features that another participant derived from the same package and published under the MIT licence (Section 2). No removed reference layer, no copy of one and no outside dataset was used.

Code, outputs and checksums: the full package described in Section 8 is public at https://github.com/HyunsikParker/bias-bounty-coverage-gaps.

1. Summary

The organisers removed the TIGER roads, Microsoft building footprints, facility points and County Business Patterns counts from the package on 25 September. Since then no file in it carries a label or a reference denominator, so a component gap cannot be computed the way the methodology describes. Two things remain: tract features built from the package that track each component, and the public leaderboard, which reports one RMSE per uploaded file.

Our first estimator turned the features into component gaps against estimated denominators and averaged them. Its mean was 0.311, while the public target mean is 0.060, and it scored worse than a constant at its own mean (0.2787 against 0.2663). The estimator behind the selected submissions keeps the features as predictors and takes its scale from the leaderboard:

ŷi=y‾+∑jβj(fij−mj).\hat y_i = \bar y + \sum_j \beta_j \,(f_{ij} - m_j).

The public mean and variance of the target come from two constant files. The public covariance of each predictor with the target comes from one probe file per predictor, by solving the RMSE of that file for the covariance. The coefficients are β=Σ−1c\beta = \Sigma^{-1} c. The first four joint models scored within 0.00033 of the RMSE we predicted before uploading them; larger models drifted further above their predictions (Table 4), so we stopped adding predictors.

Every step except the leaderboard reads runs from the package with the scripts in src/. The reads themselves are listed with their submission IDs (Table 3), and with them the scripts rebuild the selected file gki9K7jy byte for byte and every value of 6BNL8pZ3 (Section 8).

3. Predictors

Each predictor stands in for one part of the published definition (Table 1). They are proxies: none of them recovers a removed denominator, and none needs to, because the calibration in Section 5 only uses how each one co-varies with the target.

Road gap. The definition compares Overture length in the motorway, trunk, primary and secondary classes with TIGER S1100 and S1200 length. Overture’s routes attribute marks segments that carry an Interstate, US or State route, which correspond closely to the TIGER S1100 and S1200 classes. We estimate the reference length as signed-route length plus county-route length and compute

giroad=1−min⁡(1,LinamedLisigned+Licounty).g^{road}_i = 1 - \min\!\left(1, \frac{L^{named}_i}{L^{signed}_i + L^{county}_i}\right).

The component counts as defined (di=1d_i = 1) when that estimated reference exceeds 0.1 km. The predictor road_g1 is giroad⋅di/(di+2)g^{road}_i \cdot d_i/(d_i + 2), the road term’s share of a three-component mean, and is 0 when the road is undefined. road_g1_def is did_i itself. The methodology warns that road gaps are not comparable across regions, so road_g1_ok and road_g1_tx give Eastern Oklahoma and South-Central Texas their own slopes.

Building gap. The reference is Microsoft’s footprint count, and Overture imports many Microsoft footprints, so the composition of a tract’s Overture buildings says something about how complete they are. The building predictors are the OpenStreetMap and Esri shares of Overture buildings, the share of footprints under 40 m², and log⁡(1+Bi/max⁡(HUi,1))\log(1 + B_i / \max(HU_i, 1)), buildings per housing unit.

POI gap, facilities half. The reference counts fire stations, EMS stations and schools. fire0_rural equals the rural share, one minus pct_urban, when no place is filed as fire_department, and 0 otherwise. fire_evidence marks tracts with no fire_department place that still hold a fire-protection-service place or a fire-department name in another category, and fire_classdesert marks the 333 scored classification deserts above. school0 and school_evidence do the same for schools. No EMS predictor entered a fit: its name evidence is non-zero in under 3% of tracts, too sparse for a probe to measure.

POI gap, establishments half. The reference is County Business Patterns establishments. cbp_lowplaces is clip⁡(1−ri/r̃,0,1)\operatorname{clip}(1 - r_i/\tilde r, 0, 1), where rir_i is Overture places per housing unit and r̃=0.0861\tilde r = 0.0861 its median over tracts with more than 50 housing units.

Region. Indicators for Eastern Oklahoma, Maricopa and Northern California, with South-Central Texas as the base.

4. Why the first estimator failed

Before any leaderboard read, the first pipeline estimated every removed denominator from housing units, land area and road length, with quantile calibration by urban band, and averaged the defined component gaps. We submitted six of its files on 7 October, each testing one question (Table 2).

The composite lost to a constant at the same mean, and raising the denominators made it worse. The target moments (Section 5.1) explain why. The target averages 0.060 with standard deviation 0.089, so most tracts have almost no gap, and a model centred at 0.31 misses nearly every tract by more than any variation it captures. The constant 0.060 alone would score 0.089. The package holds nothing that fixes this scale, so we took it from the leaderboard (Section 5).

5. Calibration from public-leaderboard moments

5.1 Target moments

Write PP for the public split (about 30% of the 9,379 scored tracts). For a constant prediction kk, RMSE2=EP[y2]−2ky‾+k2\mathrm{RMSE}^2 = E_P[y^2] - 2k\,\bar y + k^2. An all-zero file scored 0.107246 after the 2 October scorer change, as participant Kimyayd reported in thread 35079, which gives EP[y2]=0.0115017E_P[y^2] = 0.0115017. Our constant 0.31080482 scored 0.266318147. Together they give y‾=0.059806\bar y = 0.059806 and a standard deviation of 0.089022. The same participant reported 0.059806 for the all-zero file under the scorer before 2 October and read that metric as a mean absolute error. For a non-negative target and an all-zero file, the mean absolute error equals the mean, so the two values agree. The scripts carry y‾=0.059802\bar y = 0.059802, which we derived with the constant rounded to 0.3108. The 0.000004 difference shifts every prediction by that amount and changes no reported RMSE.

5.2 Probes

A probe for predictor ff predicts y‾+a(fi−m)\bar y + a(f_i - m) in the four scored regions, where mm is the mean of ff over the scored tracts, and y‾\bar y in Eastern Washington. The file format requires the Eastern Washington rows, but they are not scored. Expanding the squared error gives

RMSE2=VarP(y)−2aCovP(y,f)+a2EP[(f−m)2],\mathrm{RMSE}^2 = \mathrm{Var}_P(y) - 2a\,\mathrm{Cov}_P(y, f) + a^2 E_P\!\left[(f - m)^2\right],

which we solve for CovP(y,f)\mathrm{Cov}_P(y, f). Since the scored-tract value of E[(f−m)2]E[(f - m)^2] stands in for its public value, the read assumes that the public split is a random subset. We chose each aa so that predictions stay in [0, 1] and the RMSE moves by far more than the nine displayed decimals. src/lbreg_probe.py writes a probe file and converts a read into a covariance, a correlation and the best RMSE that predictor alone could reach.

5.3 Joint estimator

Σ\Sigma is the covariance matrix of the chosen predictors over all scored tracts, so it uses every tract rather than the public 30% only. cc is the vector of probed covariances. Then β=Σ−1c\beta = \Sigma^{-1}c, and before clipping the expected public RMSE is VarP(y)−c⊤Σ−1c\sqrt{\mathrm{Var}_P(y) - c^\top \Sigma^{-1} c}. 6. Edge cases

  • GEOID as text. Every script reads GEOID as a string, and every submission keeps the sample files’ GEOIDs and row order, so Maricopa’s 04… tracts keep their leading zero and every join succeeds.
  • Eastern Washington. The scorer rejects a file without its 415 rows, but they are not scored. They are set to y‾\bar y and excluded from every mean, covariance and fit.
  • Tracts with no Overture data. Two scored tracts, 48039990000 and 48057990000 (Texas water tracts), hold no Overture road, building or place. A tract in the authoritative sample has at least one defined component, and with a zero Overture numerator any defined component has a gap of 1, so their score is 1. FNBceCuK predicts 0.0527 for both, because the linear model sees only all-zero features. src/edge_no_overture.py applies the rule from the 15 October files on, including both selected files. The first, knE1GJ3o (17 predictors), read 0.076163 on 15 October: one public tract with target 1 gives 0.075837 plus the offset of Table 4 (none would give 0.077938, both 0.073677).
  • Zero-population and zero-housing tracts. The 26 scored tracts with no population are exactly the tracts with no pct_urban. The code treats a missing urban share as fully urban, which sets fire0_rural to 0 rather than guessing a rural share. 80 tracts have no housing units and 101 have 50 or fewer. Every per-housing-unit quantity divides by max⁡(HUi,1)\max(HU_i, 1), and cbp_lowplaces is set to 0 at 50 housing units or fewer, where a single shop moves places per housing unit a long way.
  • Undefined road component. 2,897 scored tracts (30.9%) have no estimated reference road: 64.3% in Maricopa, 31.3% in Northern California, 23.7% in Eastern Oklahoma and 23.4% in South-Central Texas. The organisers report that at least one component is undefined in 55%, 37%, 21% and 28% of tracts in the same regions. That is not the same quantity, but Maricopa stands far above the others in both. For such tracts road_g1 is 0 and road_g1_def lets the fit move their level, which stands in for the varying divisor of the reference mean.
  • Data-sparse tracts. 70.7% of scored tracts have no fire_department place and 21.6% no school place. A zero count cannot tell a tract without a station from a tract whose station is missing, so the facility predictors weight zero counts by rurality (fire0_rural) or require evidence that a station exists under another category (fire_evidence, fire_classdesert, school_evidence).

7. Alternative weightings and why

  • Equal weights on proxy components (Section 4) put the mean at 0.31 and lost to a constant. With the reference denominators gone, nothing in the package can set the scale of the components.
  • Single predictors (Table 3) reach at best 0.0848 (bld_osm_share). The predictors carry partly separate information, so the 13-predictor model reaches 0.0787.
  • Region-specific road slopes. The road predictor restricted to Eastern Oklahoma correlates with the target at 0.287 and the one restricted to South-Central Texas at 0.113, in line with the organisers’ note that the TIGER-to-Overture length ratio differs by region (0.71 to 1.59).
  • No shrinkage; selection stopped at 25 predictors. The fits estimate 13 to 27 coefficients from covariances measured on about 2,800 public tracts. The optimism of an in-sample fit is of order p/n, under 1% of the variance here, so we did not shrink the coefficients. Table 4 shows the cost growing with p: the read sits 0.0003 above prediction at 17 predictors and 0.0007 above it at 27, and the 25- and 27-predictor files read worse than the 21-predictor one. We selected the 21-predictor file, our best public read, and the 25-predictor file, and stopped probing.

9. Limitations

  • The coefficients rest on the public 30%. If the split is not random, or the private tracts relate to the predictors differently, the private score will be worse than the public one by more than the usual noise. On the private leaderboard shown on 1 November, while the top solutions were still under code review, gki9K7jy read 0.078014 and 6BNL8pZ3 0.078044, both about 0.0026 above their public reads. That is more than the roughly 0.0004 the p/n optimism of 21 coefficients would explain, which points to differences between the public and private tracts or to more noise in the probed covariances than we assumed.
  • Each covariance comes from one read rounded to nine decimals, and EP[(f−m)2]E_P[(f - m)^2] is replaced by its value over all scored tracts. Table 4 bounds the combined error at about 0.0003 in RMSE for the models we submitted.
  • The predictors rank tracts; they do not estimate any removed reference count, and the model does not produce component scores.
  • Most predictors come from another participant’s feature files. We verified the counts we use against our own build (Section 2), but any error common to both builds would pass that check.
  • The method uses the public leaderboard as a measuring instrument: each read yields one covariance. We list every read so that a reader can judge that choice and reproduce the coefficients.
